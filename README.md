# Woordje

Scan a Dutch text with your phone camera, OCR it in the browser, and tap any word on the image to see its meaning and track it as New, Learning or Learned.

The app lives in `woordje/` (static site, no build step). Netlify publishes that folder (see `netlify.toml`).

`index.html` at the repo root is an unrelated game (Star Catcher).
